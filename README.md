# Учебный VR-комплекс

Интерактивное предложение по разработке учебного комплекса для
Университета общественной безопасности Республики Узбекистан.
Версия от 27.10.2026. Без коммерческих условий.

**[Открыть интерактивное КП](https://artnov952-spec.github.io/university-vr-practice/)**

[Сразу открыть демо программы](https://artnov952-spec.github.io/university-vr-practice/#demo)

[Репозиторий](https://github.com/artnov952-spec/university-vr-practice)

## Возможности

- Предложение на русском и узбекском языках, только светлая тема.
- Девять страниц-слайдов. Четыре отдельные интерактивные среды, по пять ситуаций в каждой.
- Пять CG-панорам: махалля, подъезд, перекресток, базар и аудитория.
- Восемь этапов занятия с работающими интерактивными примерами.
- 100 цельных CG-кадров этапов: согласованные масштаб, перспектива и освещение вместо отдельных наклеенных объектов.
- Короткие инструкции для всех действий на русском и узбекском. Локальный разбор и переход к расчету выбранного примера.
- Выбор ситуации сразу показывает ее участников и обстановку, еще до отметки первого действия. Первая отметка фиксирует начальное наблюдение; следующие этапы меняют кадр.
- Демонстрация программы: 14 модулей, подготовка, практика, разбор и аналитика.
- Локальная подготовка примера обмена с E-reyting, без реальной отправки.

## Запуск

Сайт не требует установки зависимостей и сборки.
Из корня репозитория:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8766/`. Прямое открытие HTML через `file://`
не подходит для модулей JavaScript.

Проверка файлов и локальных моделей на Node.js 22 или новее:

```sh
npm test
```

## Границы Демонстрации

Это предложение и браузерная модель, не промышленная система университета.
Все начальные учебные данные вымышлены. Изменения сохраняются только
в браузере посетителя. Реальной авторизации, серверной базы, подключения
шлемов и API E-reyting нет. Браузерные роли не являются защитой доступа.

Основа панорам является CG-иллюстрацией с обзором из одной точки.
Цельные кадры меняются по ручным учебным действиям, в том числе в панорамном просмотре.
Это иллюстративные состояния, а не непрерывная анимация или физическая симуляция.
Это не свободное перемещение, распознавание действий или измеренная 3D-реконструкция. Методика
и академические пороги требуют утверждения университетом.

В репозитории нет исходных PDF, переписок, секретов, личных сохранений,
настроек хостинга или внутренней истории разработки. Директива `noindex`
сохранена: публичная ссылка не означает запрос индексации в поиске.
